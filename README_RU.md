# Beyond the Bag — Minecraft 1.20.1

**Платформа:** Minecraft Java 1.20.1 · Forge 47.2.0 · Java 17  
**Версия проекта:** `1.0.0-dev` — разработка, не финальный релиз.

## Что есть в текущем исходном проекте

- Предмет «Мешок измерений», рецепт и русская локализация.
- GUI мешка: личное пространство, нестабильный лабиринт и возврат.
- Серверная обработка действий через Forge SimpleChannel.
- Сохранение исходного измерения, координат и поворота игрока.
- Безопасный возврат к спавну, если исходное измерение недоступно.
- Персональная область в карманном измерении, создаваемая один раз.
- Начальная генерация площадки, деревьев и пруда.
- Перегенерируемый лабиринт с комнатами, проходами, ловушками и сундуками.
- Серверный директор экспедиции: рост уровня нестабильности, случайные звуковые/визуальные эффекты, появление преследователей на базе ванильных существ и событие босса на базе Хранителя.
- GitHub Actions для облачной сборки.

## Что ещё не реализовано

Этот проект **не является завершённым релизом 1.0.0**. Директор лабиринта пока использует ванильных мобов с именами и эффектами, а не отдельные модели, текстуры и уникальный AI. Также не завершены полноценная природная генерация биомов, независимые экземпляры личных измерений, система приглашений/ролей, полноценные уникальные боссы и их механики, полноценная система секретных комнат/событий, балансировка и игровые тесты. Эти функции нельзя считать готовыми только потому, что проект собирается.

## Сборка в GitHub Actions

1. Загрузи содержимое архива в корень репозитория `Beyond-the-Bag`, заменив старые файлы.
2. Открой **Actions** и дождись запуска `Beyond the Bag Build`.
3. Если сборка успешна, скачай артефакт `Beyond-the-Bag-1.0.0-dev`.
4. Помести JAR в `mods` профиля Minecraft 1.20.1 с Forge 47.2.0 и Java 17.

Если сборка упадёт, пришли полный лог шага **Build Forge mod**. Зелёный статус подтверждает только компиляцию, но не гарантирует отсутствие ошибок во время игры.
