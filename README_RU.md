# Beyond the Bag — техническая альфа 0.1.1

**Целевая среда:** Minecraft Java 1.20.1, Minecraft Forge 47.2.0, Java 17.

## Управление текущей альфа-версией
- Мешок измерений добавлен в творческую вкладку «Инструменты и утилиты».
- Рецепт: кожа, жемчуг Края, золотые слитки и фиолетовый краситель (см. `data/beyondthebag/recipes/dimension_bag.json`).
- Обычный ПКМ мешком — вход в новую вылазку-лабиринт.
- Shift + ПКМ — вход в личную строительную область.
- ПКМ мешком внутри карманного измерения — возврат.

## Сборка
Требуются JDK 17 и Gradle 8.x. В корне проекта:

```bash
gradle build
```

Результат успешной сборки должен появиться в `build/libs/`.

## Что изменено в этой итерации
- Добавлен рецепт мешка.
- Мешок добавлен в творческую вкладку.
- Обновлены русская и английская локализации.
- Добавлена резервная точка возврата на мировой спавн, если сохранённое измерение или координаты недоступны.

## Ограничения и честный статус
Это техническая альфа, не готовый релиз. Личная область и лабиринт пока размещаются в одном общем измерении на разнесённых координатах. Это не полноценные отдельные миры на каждого игрока и не гарантирует строгую изоляцию при совпадении координатных слотов.

Пока не реализованы: графическое меню, отдельная система личных миров, полноценная система комнат/секретов/ловушек/аномалий, приглашения и серверная система прав, полная обработка смерти и аварийного отключения, комплексная очистка всех следов старой вылазки.

Сборка и запуск в Minecraft в этой среде не выполнялись: здесь отсутствуют Gradle и JDK 17 (установлена Java 21). Не устанавливай эту альфу на основной мир без резервной копии.

## Облачная сборка через GitHub Actions (с телефона)

В проект добавлен workflow `.github/workflows/build.yml`. Он собирает мод автоматически на GitHub с Java 17 и Gradle 8.1.1.

1. Создайте на GitHub новый пустой репозиторий (например, `Beyond-the-Bag`). Не добавляйте README, лицензию или `.gitignore` при создании.
2. Распакуйте ZIP проекта на телефоне.
3. Откройте репозиторий на GitHub в браузере. Через **Add file → Upload files** загрузите содержимое папки `beyond_the_bag` (именно файлы и папки внутри неё, включая скрытую папку `.github`). Если мобильный интерфейс не показывает скрытые файлы, включите отображение скрытых файлов в файловом менеджере или загрузите проект через GitHub Desktop/веб-версию с компьютера.
4. Нажмите **Commit changes**.
5. Откройте вкладку **Actions**, выберите **Build Beyond the Bag** и дождитесь завершения workflow.
6. В успешном запуске внизу страницы откройте **Artifacts → beyond-the-bag-jar** и скачайте архив. Внутри будет собранный `.jar`.

Если сборка завершилась ошибкой, откройте запуск в Actions, скопируйте лог красного шага **Build mod** и передайте его разработчику. Сам факт наличия workflow не означает, что мод уже успешно собран или протестирован в Minecraft.
