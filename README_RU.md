# Beyond the Bag — 0.2.0-alpha

Minecraft Java Edition 1.20.1 • Minecraft Forge 47.2.0 • Java 17

## Что входит в эту альфа-версию

- Предмет «Мешок измерений» и его рецепт.
- Отдельное измерение `beyondthebag:pocket`.
- Вход в личную область (Shift + ПКМ) и в нестабильную область (ПКМ).
- Сохранение точки возврата и безопасный возврат в исходное измерение.
- Постоянная область личного пространства с очищенной стартовой площадкой.
- Перегенерируемый лабиринт с потолком, стенами, случайными проходами, освещением и сундуками.
- Очистка области лабиринта при новой вылазке; область личного пространства не входит в область сброса.

## Управление

- **ПКМ** по мешку: войти в нестабильное пространство; если игрок уже внутри карманного измерения — вернуться.
- **Shift + ПКМ** по мешку: войти в личное пространство; если игрок уже внутри карманного измерения — вернуться.

## Важно: статус разработки

Это альфа, а не финальный релиз. В этой версии личные области размещаются в одном техническом измерении на разнесённых координатах. Это не является полной защитой от пересечения областей при коллизии UUID и пока не реализует серверную систему приглашений/прав доступа. Графическое меню выбора, полноценная независимая природная генерация личного мира, развитая система аномалий, ловушки и полноценная мультиплеерная изоляция ещё не реализованы.

Перед использованием в основном мире сделайте резервную копию сохранения. Не устанавливайте одновременно несколько разных версий Beyond the Bag.

## Сборка

Требуется JDK 17. В корне проекта выполните:

```bash
gradle build --no-daemon
```

Готовый JAR появится в `build/libs/`.
