# Beyond the Bag — проект для Minecraft 1.20.1

**Целевая платформа:** Minecraft Java 1.20.1 · Forge 47.2.0 · Java 17  
**Версия исходников:** `1.0.0-dev` (разработка, не финальный релиз)

## Уже реализовано в этой сборке исходников

- Предмет «Мешок измерений» и рецепт крафта.
- Русское меню мешка с выбором личного или нестабильного измерения и возвратом.
- Серверная обработка действий через Forge SimpleChannel.
- Запоминание исходного измерения, координат и поворота игрока.
- Безопасный возврат на точку появления мира, если исходное измерение недоступно.
- Персональная область личного пространства, которая создаётся один раз и не очищается при повторном входе.
- Первичная генерация холмистой площадки, деревьев, пруда и точки прибытия.
- Обновляемая при каждом походе область лабиринта с комнатной сеткой, случайными проходами, тайниками, ловушками и сундуками.
- GitHub Actions для сборки JAR на Java 17.

## Важные ограничения текущей версии

Это рабочая основа проекта, а не готовый релиз 1.0.0. В этой версии ещё нет полноценной природной генерации биомов, настоящей изоляции личных измерений на уровне отдельных dimension instances, приглашений друзей и системы ролей, собственных моделей/AI монстров и боссов, пятиступенчатой системы нестабильности, полной системы событий/звуков и комплексного тестирования на клиенте и выделенном сервере. Не устанавливай эту dev-сборку как обещанный финальный релиз.

## Сборка через GitHub Actions

1. Загрузи содержимое архива в корень репозитория `Beyond-the-Bag` (замени старые файлы).
2. Открой вкладку **Actions**.
3. Запусти **Beyond the Bag Build** или дождись автоматического запуска после push.
4. Если сборка успешна, открой завершённый запуск и скачай артефакт `Beyond-the-Bag-1.0.0-dev`.
5. JAR из архива помещается в папку `mods` вместе с Forge 47.2.0 и Java 17.

Если Actions завершится ошибкой, пришли полный лог шага **Build Forge mod**. Зелёная галочка подтверждает компиляцию, но сама по себе не доказывает корректность всех игровых механик.

## Структура

- `src/main/java` — код мода.
- `src/main/resources` — ресурсы, локализация, рецепт и описание измерения.
- `.github/workflows/main.yml` — облачная сборка.
